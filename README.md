# PolyU Twin

Product page for the PolyU digital twin platform: one drone survey of the PolyU campus and Hung Hom builds a reality model, semantic labels and an automatically generated building model; rooftop solar (potential, roofs, layout, grid forecast, drone inspection) runs on top of it.

Static page (`index.html` + `assets/`), served with GitHub Pages. Images are renders from the platform; figures come from the same platform run (2 Nov 2026).
